# BEYOND — Space & Astronomy Portal

## O projekcie
BEYOND to nowoczesna strona internetowa poświęcona astronomii, kosmosowi i odkryciom naukowym. Projekt tworzony jest w PHP, HTML i CSS.

## Technologie
- PHP — logika strony i obsługa API.
- HTML5 — struktura.
- CSS3 — wygląd i responsywność.
- JavaScript — tam, gdzie jest potrzebny.
- JSON — przechowywanie ciekawostek i informacji o misjach.

## Wygląd
Połączenie futurystycznego dashboardu astronomicznego i nowoczesnego portalu naukowego.

## Podstrony

### 1. Strona główna — index.php
Interaktywny dashboard zawierający:
- Galactic Overview — informacje o Drodze Mlecznej.
- Exoplanet Discovery — statystyki odkrytych egzoplanet.
- Star Classification — klasyfikacja gwiazd.
- Black Hole Analysis — informacje o czarnych dziurach.
- Discoveries — odkrycia astronomiczne.

### 2. Układ Słoneczny — uklad.php
- Prezentacja Słońca i ośmiu planet.
- Karty planet z podstawowymi danymi.
- Opisy, zdjęcia i ciekawostki.
- Możliwość wyświetlenia szczegółów wybranej planety.

### 3. Zdjęcie dnia — apod.php
Integracja z NASA APOD API:
https://api.nasa.gov/

Jednak czat inaczej to rozwiązał bo to API NASY nie działa.

### 4. Artykuły — odkrycia.php
Miały być odkrycia ale jednak są artykuły - krótkie informacje na różne tematy zawarte w 12 artykułach.

### 5. Ciekawostki — ciekawostki.php
- Ciekawostki astronomiczne.
- Przycisk losowania kolejnej ciekawostki.

### 6. Misje kosmiczne — misje.php
Informacje o misjach takich jak Apollo 11, Voyager, Cassini, Perseverance, James Webb i Artemis.
